## Outside scope

- `PartFormPage` (`pages/part-form.page.ts:44`) does not extend `BasePage`, while UI §4 says every page object does. It is a modal form, so this may be intended; the convention should say so, or the class should be a component.
- `FormComponent.root` is `page.getByRole('dialog')` (`form.component.ts:21`): any second dialog (e.g. a confirmation) would make every form locator ambiguous.
- `SelectComponent.select` clicks `.first()` of the options containing the text (`select.component.ts:28`) without a comment; it is safe with unique QA names but could pick the wrong option for demo-data names.
