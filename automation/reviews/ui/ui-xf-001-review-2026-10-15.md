## Outside scope

- `pages/part-form.page.ts:44` (`PartFormPage`, existing) does not extend `BasePage`, contrary to UI §4. The new form pages copy that pattern. Either the convention or the form page objects should change (architect's decision).
- `fixtures/data.fixture.ts:28-30`: `data.post` registers no cleanup, so any spec using it leaks records unless it cleans up some other way. Consider making `post` take a delete path, or documenting that it is untracked.
- `pages/parts.page.ts:40-47`: `switchView` clicks a `button` named `segmented-icon-control-<view>` while `viewToggle` returns a `radio` with the same name. Two locators for one control; fine if both roles exist, but worth unifying.
