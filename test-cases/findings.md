# Findings

Mismatches between the InvenTree docs, the assignment brief and the actual behaviour of InvenTree 1.5.6, plus suspected product bugs.

| ID | Area | The source says | The app does | Evidence | Effect on tests |

UI-Part-004 changed. Doc issue 13. |

Doc issue 14. |
